Simple 4-Step Workflow

How GSTSyncPro Reconciliation Works

From as-is portal file upload in 2-Files Mode to side-by-side review, complete ITC summary, and 1-click GST portal JSON export. All processing happens 100% locally inside Chrome.

1

Select Upload Mode (2-Files or 4-Files)

Open GSTSyncPro in Chrome. In 2-Files Mode, upload your GST Portal file (GSTR-2B / IMS) completely as-is without editing, alongside your Books file. In 4-Files Mode, use standard template column headers for separate Purchase and Credit/Debit Note files.

2

Smart Auto-Matching

Select GSTR-2B vs Books or IMS vs Books mode and click Reconcile. GSTSyncPro runs multi-pass auto-matching algorithms with clean comma parsing for exact amount precision.

3

Side-by-Side Pairing Review

Review unmatched and pending entries side-by-side in Chrome. Auto-matched transactions are processed as Accept, while unmatched entries default to Pending in the side-by-side view specifically for manual Pair, Force Pair, or Unmatch overrides. Not-filed entries are ignored.

4

1-Click Export

Export your reconciliation as a portal-compliant IMS Action JSON file for direct GST Portal upload, formatted Excel sheets for office records, and print-ready PDF reports for clients.

Data Privacy

Your GST Data Never Leaves Your Browser

All file parsing, matching, and ITC calculation happens entirely inside your Browser. Only license validation communicates with our server — no GSTIN, invoice, or financial data is ever transmitted.
